# Web Development Projects (HTML, CSS, JavaScript)

Frontend coursework and interactive web applications developed at the Academy of Economic Studies of Moldova (ASEM).

## Included Projects
* **Gaming Platform Landing Page:** Responsive multi-section web layout implemented from a Figma design using semantic HTML5, modern CSS (Flexbox/Grid), and custom UI assets.
* **Smart Shopping Discount Calculator:** Interactive JavaScript application calculating tiered price discounts, final totals, and dynamic UI feedback.

## Technologies
* HTML5, CSS3, Vanilla JavaScript (ES6+)
* Figma (UI/UX Prototyping), WebStorm, Git
